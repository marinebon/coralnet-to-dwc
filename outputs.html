The zip file is ready to upload to the IPT.

What is in each table?

Events

The first row is the parent event for the survey. The other 207 rows are the photo events. Each photo event has its own latitude and longitude.

Occurrences

Each row is one taxon in one photo. The row has the scientific name, the AphiaID, the percent cover, the person or machine that identified it, and the field group’s recordedBy string.

Measurements

The eMoF table has seven kinds of measurement:

measurement rows unit
quadrat area 207 square metres
camera height above substrate 207 centimetres
number of points classified as non-taxon 207 counts
percent cover 504 percent
number of points 504 counts
machine-annotated points 504 counts
human-annotated points 504 counts

The archive

The zip file contains:

  • event.csv
  • occurrence.csv
  • extendedmeasurementorfact.csv
  • meta.xml
  • README.txt

meta.xml tells the IPT which column is which Darwin Core term. The column order in the CSV files must match meta.xml. The script writes both, so they stay in step.

Note

The script does not make EML. Add the dataset title, abstract, methods, and licence in the IPT.
