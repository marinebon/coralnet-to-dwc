The data

The example uses three CSV files from CoralNet.

file rows what it is
metadata.csv 207 one row per photo
annotations.csv 20,700 one row per point
labelset.csv 15 the CoralNet label list

The scripts read only metadata.csv and annotations.csv. The label list is useful for checking the result.

The photos

Each row in metadata.csv has:

  • the image name
  • the date
  • the latitude and longitude
  • the camera height
  • the camera name (the short name TG-7)
  • the field group

All 207 photos are from one survey. The date is 2026-10-20. The place is Forte do Negrito, Terceira, Azores, Portugal. The habitat is rocky intertidal, midtide level. The photos are divided into four field groups: Group_1 to Group_4.

The camera is the OM System Tough TG-7. The Camera column uses the short name TG-7. The scripts write the full camera name in the event remarks.

The GPS positions come from the GPS built into the OM System Tough TG-7 camera. Photo events use a position uncertainty of 1 metre. The parent event uses 500 metres because it represents the full beach, not one photo position.

The points

Each row in annotations.csv is one point in one photo. Each photo has 100 points. The file has 20,700 rows.

The important columns are:

column meaning
Name the image name
Label code the short CoralNet label
Label ID the CoralNet label number
Annotator the CoralNet username

The annotator can be a person or robot. robot means the automated classifier.

These labels are left out:

label why
SC substrate, not a taxon
Unc unclear, not a taxon
LICHEN generic lichen, not one taxon
MAF filamentous macroalgae, functional group
MAEN encrusting macroalgae, functional group
Important

CIRRIPE is a generic barnacle label. It is mapped to Chthamalus stellatus because that is the barnacle in these photos. Please review this mapping.

RVL has two points in two photos. Please review these records before publishing.

The names

recordedBy is free text at the top of the script. There is one string for each field group, and it is written to the occurrence table. It is not read from the CSV files. If a group has more than one recorder, the names are separated by |.

identifiedBy lists the CoralNet usernames for human annotations. The CoralNet robot value is written as CoralNet machine learning annotator. A mixed row can have more than one name, separated by |.

The current 2026 data has no Imported value in the Annotator column. If that value appears in another export, see the explanation in Notes.

The taxonomy

Each taxon in the script has a WoRMS AphiaID. The occurrence ID ends with that number. For example:

MBON-P2P:20261020:PRT:TER:FDN:MIDTIDE:G1:IMG0128:aphia-144296

The last part, aphia-144296, is Ulva.

The taxonomy is written in the script. A new survey may need new names and new AphiaIDs.
